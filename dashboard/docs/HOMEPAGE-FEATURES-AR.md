# اختيارات الصفحة الرئيسية — Find News

قسم أعلى Built around real spatial decisions، يستخدم نفس عنوان وغلاف ووصف السجل، مع رابط للتفاصيل. اسم القسم المؤقت داخل `website/scripts/homepage-features.cjs` في ثابت `TITLE`.

## الماركتنج

- في Blog أو Use Case، فعّل **Feature on homepage** ثم احفظ وانشر.
- **Homepage order** رقم من 0 إلى 9999؛ الأصغر يظهر أولًا في القسم فقط، دون تغيير ترتيب قوائم Blogs أو Use Cases أو Solutions.
- الحد الأقصى حالتان ومقالان منشوران. إذا امتلأ النوع، ألغِ اختيار سجل قديم وانشره أولًا، ثم اختَر البديل وانشره. لا يحدث استبدال تلقائي.
- يمكن حفظ اختيارات المسودات إذا بقيت سعة؛ يُعاد التحقق وقت النشر لمنع تجاوز الحد.
- الحفظ وحده لا يغير الموقع. يظهر التعديل عند Publish ثم فتح الهوم بيج أو Refresh.
- Unpublish يزيل السجل فور تحديث الصفحة. إذا خلت الاختيارات المنشورة، يختفي القسم. لا نملأه تلقائيًا بأحدث محتوى.
- الروابط الأصلية والكروت في القوائم تظل كما هي؛ اختيار الصفحة الرئيسية مستقل عن Feature in Solutions menu.

## التيم

- حقلا `featureOnHomepage` و`homepageOrder` على النوعين، مع صلاحيات المحتوى الحالية للمحرر والناشر؛ المحرر لا يكتسب صلاحية النشر.
- الاختيارات تُقرأ من Strapi عند الطلب، باستخدام توكن القراءة الحالي في سيرفر الموقع، وبدون كاش للصفحة الرئيسية.
- عند فشل مصدر محتوى لا نستبدله بنسخة قديمة. تبقى الهوم بيج متاحة مع المحتوى المتاح فقط.
- الحد مفروض على السيرفر. تتابع العمليات داخل نسخة SQLite المحلية؛ وقفل معاملة PostgreSQL يحمي السعة عبر نسخ Strapi عند النشر باستخدام PostgreSQL. اختبار PostgreSQL فعلي مطلوب ضمن تجهيز بيئة النشر.
- لا تعتمد هذه الميزة على build جديد عند تعديل المحتوى؛ أول نشر للكود يتطلب تحديث CMS والموقع معًا.
