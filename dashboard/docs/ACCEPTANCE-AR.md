# الاختبارات وتسليم التجربة

## الاختبارات السريعة

```powershell
npm test
```

تغطي النص المسموح ومنع حقن HTML والروابط المحجوبة، توقيع المعاينة وانتهائه، قراءة كل صفحات API، وصورة فقط بدون مشغل أو زر فيديو.

## اختبار الربط الحقيقي

شغّل CMS والموقع، ثم من الجذر:

```powershell
node scripts/integration.cjs
```

هذا اختبار محلي على SQLite الحالية. يقارن الحالات السبع بالنصوص الأصلية حرفيًا، ثم ينشئ حالة اختبار مؤقتة ويتحقق من Save/Preview/Publish/Unpublish والرابط والقائمة وSolutions وخريطة الموقع. يحذف حالة الاختبار في النهاية. لا تستخدمه على بيانات إنتاج؛ يعتمد عدد الحالات السبع الأولية وينشئ مستخدمي QA مؤقتين للتجربة.

## اختبار المتصفح

بعد اختبار الربط:

```powershell
npm ci
# إن لم يوجد Chrome محلي أو Chromium الخاص بـPlaywright:
npx playwright install chromium
node scripts/browser-qa.cjs
node scripts/editor-qa.cjs
node scripts/content-parts-qa.cjs
node scripts/part-position-qa.cjs
node scripts/seo-qa.cjs
```

Playwright اعتماد تطوير في جذر التجربة فقط، وليس اعتمادًا على سيرفر الإنتاج. تستخدم الاختبارات عناوين الخدمة من `website/.env` وChrome المحلي على Windows إذا وجد، وإلا Chromium الخاص بـPlaywright. يمكن ضبط `CHROME_PATH` لمسار متصفح آخر. ملفات الصور وبيانات QA تحفظ في `artifacts/` المتجاهل. لا ترفع بيانات الدخول أو الملفات المؤقتة.

الاختبار الأول يفحص البحث والأغلفة والتجاوز الأفقي على عرض 390 و768 و1440. الثاني يختبر أدوات الكتابة والحفظ، حقول الفيديو المشروطة، Preview داخل اللوحة، فصل صلاحيات المحرر عن الناشر، وقفل الرابط بعد النشر. التكرار المتسارع لتسجيل الدخول قد يفعّل حد Strapi للطلبات؛ انتظر قبل إعادة تشغيله، ولا تعطّل الحماية.

`node scripts/media-qa.cjs` يختبر استيراد غلاف YouTube الحقيقي وإنتاج النسخ، وصورة صغيرة لا تُكبّر بعد القص. يحذف سجلاته وصوره المؤقتة بعد الاختبار. يحتاج اتصالًا بـYouTube.

`node scripts/cover-focus-qa.cjs` بعد تجهيز حسابات QA بالأمر `node scripts/prepare-qa.cjs` يختبر تكبير وتحريك غلاف 16:9 فعليًا باستخدام صورة ألوان مؤقتة، ويقارن البكسلات في المحرر ومعاينتي الصفحة والكارت والموبايل بالملف المقصوص. يتحقق من الحفظ وإعادة الفتح وعدم ظهور قص المسودة للعامة قبل Publish، وزر Reset crop وحدود التكبير. يحذف السجل والصور التي أنشأها فقط. لا تعدّل حسابات التيم لهذا الاختبار، واحذف حسابات QA بعد الانتهاء.

لاختبار المعاينة أثناء الكتابة دون افتراض عدد الحالات الحالية، استخدم `node scripts/prepare-qa.cjs` ثم `node scripts/live-preview-qa.cjs`. يختبر صفحة جديدة قبل الحفظ، والعنوان والوصف والمحرر والغلاف وتغيير نوع الميديا ومعاينة الكارت والموبايل، ويتأكد أن قاعدة البيانات والصفحة العامة لا تتغيران. احذف حسابات QA بالأمر أدناه بعد الانتهاء.

بعد انتهاء QA:

```powershell
node scripts/cleanup-qa.cjs
```

يحذف حسابات الاختبار المحلية وملف بيانات دخولها. إذا لم يُنشأ حساب مالك حقيقي، ستعود شاشة إنشاء أول مسؤول عند فتح اللوحة.

## قائمة قبول المراجعة

- الحالات السبع الأصلية بنفس النص والروابط، بدون إعادة كتابة.
- حالة إضافية تنشئ كارتًا وصفحة وقائمة ديناميكيًا بدون build.
- Save لا يستبدل المنشور. Preview يعرض المحفوظ فقط.
- Publish يظهر عند Refresh، وUnpublish يجعل الصفحة 404 حتى مع وجود HTML قديم.
- الغلاف واحد في الكارت والهيرو، بنسبة 16:9 ومن دون تمديد صورة صغيرة.
- فيديو YouTube يظهر في مكانه، وصورة فقط تخفي الفيديو وزر المشاهدة.
- Add part يدعم العناوين والأحجام والقوائم والمحاذاة وBold وItalic وUnderline وStrikethrough والأخضر المحدد فقط، وصورة اختيارية يمين/يسار/فوق/تحت مع عرض قابل للتغيير. بقية محررات القوائم تظل محدودة كما هي.
- المحتوى القديم محفوظ في أول جزء؛ سؤال مستقل لم يعد إلزاميًا. Save لا يظهر تعديل الأجزاء المنشورة للعامة قبل Publish، والمعاينة الجانبية تعرض التعديل قبل الحفظ.
- Page order يحرك الأجزاء والسيكشنز عبر الصفحة كلها، بما فيها التحليل والنتائج والفيديو والعنوان وأزرار النهاية. حفظ المسودة لا يغير ترتيب المنشور، والنشر يظهر الترتيب الجديد عند Refresh، واختيار نوع صورة يخفي الفيديو دون فقد موضعه المحفوظ.
- إعدادات SEO والمشاركة تتولد تلقائيًا وتقبل overrides يدوية ثابتة مع الرجوع للتلقائي. صورة المشاركة منفصلة عن غلاف المحتوى، والكاتب والمراجع والمصادر يظهرون للزوار وفي البيانات المنظمة. الفيديو لا يحصل على تاريخ رفع مخترع، ونسخة الصورة لا تخرج VideoObject. المشاركة تتبع عنوان الصفحة وملخصها، مع إمكانية تخصيص الصورة فقط. المنشور يستخدم index/follow وcanonical ذاتيًا، حتى مع إعدادات قديمة معاكسة. المسودات والمعاينات تظل noindex/nofollow.
- تغيير رابط منشور مرفوض من السيرفر ومقفل في اللوحة.
- المحرر لا ينشر، والناشر يستطيع النشر وإلغاءه.
- رابط معاينة منتهي أو مزور لا يكشف المسودة. مفتاح القراءة والسر لا يظهران في HTML.
- عند توقف CMS، لا تعود نسخة HTML قديمة، وباقي الموقع يعمل.
- لا تظهر روابط Industries أو Workflows المخفية.

هذه التجربة لا تنشر إنتاجًا، ولا تتضمن Blogs أو نظام موافقات مدفوع أو نشر أسعار محلي. صور وفيديوهات YouTube تحتاج وصول المتصفح لخدماتها؛ الكاش أو تجاوز سياسات YouTube ليس ضمن هذا الربط.
